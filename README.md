## Overview

Waves Loopback is a virtual audio routing and monitoring plugin for routing audio between applications and DAW tracks without external hardware or third-party virtual audio drivers.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Waves Loopback** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Virtual Routing** | Route audio from any source to any destination within the DAW |
| **Monitoring** | Real-time output monitoring with low latency |
| **Multi-Channel** | Route up to eight channels simultaneously |
| **Record Enable** | Direct record enable routing for tracking from virtual sources |
